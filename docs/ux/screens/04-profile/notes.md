# 04 — Profile & Self-assessment · design notes

**Aesthetic direction.** Editorial / engineering-spec-sheet: Fraunces serif for headlines and the big level glyph, Geist sans for UI, Geist Mono for labels and metadata. Off-white surface (`#FAFAF7`) instead of pure white — feels Nordic, less SaaS, more publication. Hairline rules and uppercase mono labels frame each section as a "spec block." Magenta `#E10078` appears only on: primary CTA, the trailing punctuation dot of display headlines (a quiet brand signature), the "current" timeline node, and the position marker on the level scale.

**LevelBadge / hero.** The current level renders at 220px Fraunces light — it's the loudest element on the page. A horizontal L1→L5 scale beneath visualises position and capped range; magenta tick marks the exact spot. "Stale" indicator is wired but the realistic engineer is 4 months in, so the chip shows fresh + the date the 6-month nudge will fire.

**LevelTimeline.** Vertical rail with three filled nodes plus a hollow "joined Visma" node, reading top-down (most recent first). Each entry carries date, cycle name, level glyph, one-line label, prose context, and source pill (Self-assessment / Cross-review / Survey). The trajectory side-panel quantifies the progression (+1 across 2 cycles, vs org median +0.6/yr) so the timeline communicates *movement*, not just history. Regression would render with the same components — node colour stays neutral, the prose carries the news.

**Self-assessment modal.** Backdrop dims and blurs the profile page so context is preserved (ghost layout peeks through). All 5 questions shown on one scroll for review, but the design intent is one question per step: large serif question, mono category label, big tap targets, keyboard-first (`1–5`, `↩`, `Esc`). Q3's multi-select uses chips, Q4 uses oversized number tiles, Q5 is a serif textarea with no border-box — feels like writing on paper, not filling a form. The reveal flips to dark ink with the predicted level as the centrepiece; both follow-up actions are equally weighted because "talk to my coach first" is a legitimate, encouraged path.
