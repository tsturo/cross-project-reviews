The rules · matching & auto-assignment 3 / 19
Cross-project means cross-project

Hard rules every pairing must pass, soft signals that rank.

Hard rules · all must pass

✓
Different project
Same project = within-project review. That's not what this is.
✓
Different coach
Sharing a coach = sharing the same management context. Cross-coach is the cleanest "outside eyes".
✓
No prior pair in the last 2 cycles
Repeat pairing rarely adds new perspective.
✓
Reviewer rank strictly higher
On the 9-cell maturity grid. Exposure to one rung up is the point.
✓
Reviewer not at load cap
≤ 2 active assignments per cycle. Spread the work.

Soft signals · rank among eligible

+1
Different company (legal entity)
Broader cross-Visma exposure.
+1
Different tech stack
A .NET engineer learning event sourcing from a Python engineer — that's the point.
+2
Rank gap of one
Closer rank usually transfers better than a chasm. Gap of 3+ scored down.
+1
Lower current load
Per slot free. Spreads reviewer work evenly.
↓
Re-validated at recording time
Hard filter runs again at submit. If a reviewer changed project in the meantime, the form rejects with a clear reason.
